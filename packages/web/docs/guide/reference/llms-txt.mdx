# Give your coding assistant the same map

Nile's <a href="/nile/llms.txt">llms.txt</a> lists the public guides, and <a href="/nile/llms-full.txt">llms-full.txt</a> contains the documentation bundle. Use them to give a coding assistant the current service/action conventions, runtime APIs and examples before it changes an application.

The npm package also includes `SKILL.md` and these generated documentation files under `docs/`. Follow the application's own instructions and check its existing service registry before adding another operation.

Nile is listed on [Context7](https://context7.com/nile-js/nile). If your assistant has Context7 configured, it can retrieve library documentation through that integration. Availability and retrieved versions depend on that service and your assistant setup.

Documentation access is separate from [runtime API discovery](/guide/basics/discovery-and-agents). Reading these files does not give an agent credentials or permission to execute an application's actions.
